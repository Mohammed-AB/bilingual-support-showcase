# Bilingual Support: guided demonstration

A fictional retailer, selected demo identities and deterministic answers by default. The knowledge base includes Arabic drafts awaiting language review.

## A focused walkthrough

1. **Choose a sample identity.**
2. **ask a policy question.**
3. **open evidence.**
4. **test a boundary.**

Pause on the evidence at each decision: bilingual source citations; scoped order lookups; human handoff and action boundaries.

## Interactive access

The application is available in Mohammed's local Demo Studio. This repository deliberately does not contain a runnable source distribution. A reviewer can inspect the included materials immediately or request a guided limited-demo session through [the portfolio](https://mohammed-ab.github.io/).

## Boundaries

The default experience uses sample customers and policy fixtures. Arabic content remains a draft pending language review. No real store integration is connected.
